Rule tuner

Cut the noise without cutting the coverage

Paste a noisy alert, the rule behind it and some of the logs. We look for a narrow, defensible exclusion, show what it would hide, and refuse to hide anything that looks like an attack.

Runs only in your browser. What you paste or load here is never uploaded, saved, or sent anywhere. This page cannot make network requests at all, and it uses no cookies or storage. Reloading or closing the tab clears everything.

Read this first.

  • Your logs stay in your browser, but they can still contain sensitive details. Use Replace my identifying values below. It swaps IP addresses for generic ones (like 192.0.2.1), emails for example.com and user folder names for USER1. Put your own values back before you use a rule.
  • Tuning is not the same as fixing. Only exclude activity after you have searched historical data and confirmed what causes it. Rule text stays locked until you confirm that.
  • Some activity must never be excluded, for example an Office program starting PowerShell. These are flagged and locked. See the examples at the bottom of the page.
  • This is a helper, not a judge. It finds patterns in the sample you give it. A person has to check the result and test it.
