Cheat sheet
. any character
\d digit   \D not digit
\w letter, digit, _   \W not
\s whitespace   \S not
[abc] one of a, b, c
[^abc] anything but a, b, c
[a-z] a range
a|b a or b
* zero or more
+ one or more
? zero or one
{3} exactly 3   {2,5} 2 to 5
^ start   $ end
\b word edge
( ) group and capture
(?: ) group, no capture
(?=x) followed by x
(?<=x) preceded by x
\. a real dot (escape specials)
+? lazy: as few as possible
