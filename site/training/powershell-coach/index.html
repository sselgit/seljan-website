Five habits that make you faster

    
    
      
  1. Get-Help is your friend. Get-Help Get-Service -Examples shows real examples.
    2. 
      
  2. Get-Command finds commands. Get-Command *service* lists everything with "service" in the name.
    3. 
      
  3. Get-Member shows what you can use. Get-Service | Get-Member lists the properties and actions.
    4. 
      
  4. Names are Verb-Noun. Get reads, Set changes, New creates, Remove deletes.
    5. 
      
  5. Preview before you change. Add -WhatIf to Stop, Remove and Set commands to see what would happen without doing it.
    6. 
    





Always test on a lab machine first. Commands that change or delete things should be run with -WhatIf before the real run.
